# Logos

- `vigie-mark.svg` : le logo sur sa tuile `ui-glass`, `radius-lg` ; icône d'application, favicon, avatar du dépôt. Encres figées : anneau `ui-ink` (#f1f4f9), point `ui-live` (#ff453a), fond #0e121b.
- `vigie-mark-nu.svg` : le même sans fond, à poser seulement sur `ui-glass` ou plus sombre (l'anneau est clair). Ne pas le poser sur la carte de jour.
- Ne pas recolorer, ne pas étirer, garder autour une marge d'au moins un quart de sa largeur.
